## Submit a new project

Submit to `student-projects/<project-slug>-<random-id>/` through a fork and pull request. Use a descriptive topic and random suffix; keep personal identifiers out of new files and folder names. Keep the instructor sample unchanged.

Read [CONTRIBUTING.md](../CONTRIBUTING.md) and use the [project README template](../docs/PROJECT_README_TEMPLATE.md) before submitting.
